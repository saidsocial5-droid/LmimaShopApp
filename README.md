# LmimaShop POS (نظام كاشير احترافي متكامل)

نظام كاشير مبيعات ونقاط بيع (POS) متطور موجه للسوق المغربي والأسواق العربية، مبني باستخدام تقنيات `WPF / .NET 10.0` وقاعدة بيانات `MySQL`. ينافس أكبر الأنظمة العالمية مثل Odoo و Square و Toast مع التركيز على سهولة الاستخدام، ودعم العمل دون اتصال بالإنترنت، والاتصال اللاسلكي المباشر.

## 🚀 الميزات الرئيسية (Features)
- **شاشة كاشير متطورة (POS):** تدعم الدفع المتعدد (نقداً، بطاقة، دفع مجزأ)، وحساب الباقي تلقائياً.
- **التوافق مع القوانين (Moroccan ICE):** دعم ضريبة القيمة المضافة (TVA 20%) والتعريف الموحد (ICE) والرقم الضريبي للشركات المغربية.
- **قارئ الباركود اللاسلكي من الهاتف:** عبر تطبيق هاتف (PWA) مدمج متصل بالكمبيوتر عبر `SignalR` بسرعة خيالية (<10ms).
- **نظام المرتجعات:** معالجة المرتجعات بسهولة وإرجاع البضائع للمخزن تلقائياً مع تحديث الأرصدة.
- **نظام الولاء (Loyalty):** رصد نقاط الولاء للزبائن (نقطة لكل 10 دراهم) لزيادة ارتباط العملاء بالمتجر.
- **العروض والخصومات:** تطبيق خصومات مرنة وسريعة على المنتجات بضغطة زر (10%, 20%, 50%).
- **تقارير الإقفال (Z-Reports):** تقارير ورديات (Shifts) دقيقة، وجرد يومي للخزينة (Cash Drawer) ومراقبة العجز والزيادة.
- **وضع الدارك مود والألوان (Theming):** واجهة عصرية وسلسة.
- **أداء فائق:** بحث فوري في أكثر من 50,000 منتج في أقل من 100 ملي ثانية.

## 📦 التثبيت والاستخدام (Installation)
1. قم بتحميل أحدث نسخة من `LmimaShop_Installer.exe` من صفحة [Releases](../../releases).
2. عند فتح البرنامج لأول مرة، سيعمل معالج إعداد قاعدة البيانات `MySQL`. تأكد من أن السيرفر يعمل.
3. لتثبيت **تطبيق الهاتف**: يمكنك نقل `LmimaShop.apk` إلى هاتفك، أو فتح المتصفح على الهاتف أثناء عمل الكاشير وكتابة عنوان الكاشير (مثال: `http://192.168.1.100:8080`).

## 🛠 البناء والتطوير (Development)
- **المتطلبات:** `.NET 10.0 SDK`, `Visual Studio 2022`, `MySQL Server 8.0+`
- **البناء (CLI):** `dotnet build -c Release`
- **النشر والإصدار:** يحتوي المشروع على ملف `LmimaShopApp.iss` مخصص لبرنامج `Inno Setup` لإنشاء ملف التثبيت بصيغة EXE. كما يحتوي على `build.yml` في `GitHub Actions` للإنشاء التلقائي للإصدارات.
